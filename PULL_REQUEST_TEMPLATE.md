## Jenis Perubahan

- [ ] `feat`: Penambahan fitur atau modul baru
- [ ] `fix`: Perbaikan bug atau celah teknis
- [ ] `docs`: Pembaruan dokumentasi atau panduan
- [ ] `refactor`: Perapihan kode tanpa perubahan perilaku fungsional
- [ ] `chore`: Pemeliharaan dependensi, CI/CD, atau konfigurasi

## Pengujian & Verifikasi

- [ ] Kode telah diuji secara lokal dan seluruh pemeriksaan/linter/test terkait lulus
- [ ] Perubahan UI/dokumentasi telah diperiksa tampilannya (termasuk mode terang & gelap bila relevan)

## Kepatuhan Keamanan, Syariah & Regulasi

- [ ] Tidak ada rahasia konfigurasi (`.env`, API key, token, encryption key) atau PII/NIK asli dalam diff
- [ ] Perubahan terkait transaksi/akuntansi menjaga keutuhan pokok wakaf 100% dan pemisahan akun akad (`PSAK 112/412`)
